# Luzan Baral - Personal Portfolio

A modern, interactive portfolio website with a terminal-style interface and typing animation effects. Built with responsive design and optimized for performance.

## 🚀 Features

- **Terminal-Style Interface**: Interactive command-line inspired design
- **Typing Animation**: Dynamic text animation with blinking cursor
- **Responsive Design**: Optimized for all device sizes
- **Modern UI/UX**: Clean, contemporary design with smooth animations
- **Project Showcase**: Featured projects with live demos and source code
- **SEO Optimized**: Meta tags, structured data, and performance optimization

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript, jQuery
- **Styling**: Modern CSS with gradients, animations, and responsive design
- **Performance**: Optimized images, minified assets, lazy loading
- **Analytics**: Google Analytics integration

## 🎨 Design Features

- **Color Scheme**: Terminal-inspired with green (#0f0), cyan (#0bc), and pink (#ff0096) accents
- **Typography**: Monospace fonts for authentic terminal feel
- **Animations**: Smooth transitions, hover effects, and typing animations
- **Layout**: Flexible grid system with modern CSS techniques

## 📱 Responsive Design

- **Desktop**: Full-featured experience with hover effects
- **Tablet**: Optimized navigation and content layout
- **Mobile**: Touch-friendly interface with stacked navigation
